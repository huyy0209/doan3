# Tiến độ W9 – Logo / icon

## W9b – Đã sửa
- Vẽ lại `logo.svg` bằng hình học, không dùng font; có bảng bo góc, mũ tốt nghiệp và quyển sổ.
- Viết lại `assets/tao-icon.ps1` để tạo `img/logo-180.png`, favicon 16/32/48 và shortcut ICO 16/32/48/256 từ cùng hình học.
- Thay favicon lỗi, thêm `assets/QuanLyGiaSu.ico` và xóa các PNG trắng/thừa khỏi `wwwroot`.
- Giữ liên kết favicon/touch icon, logo sidebar và logo đăng nhập; đặt khối CSS `/* Logo (W9) */` ở cuối `site.css`.

## Kiểm tra
- `dotnet build DoAnWeb/DoAnWeb.csproj`: thành công, 0 lỗi.
- `System.Drawing.Icon` mở được cả hai file ICO; kiểm tra từng khung DIB xác nhận đủ kích thước và có pixel xanh bảng `#1D4A40`.
- `logo-180.png` có kích thước 180×180 và pixel xanh bảng; SVG hợp lệ XML.
