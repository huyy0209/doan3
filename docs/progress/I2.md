# I2 – Hướng dẫn và script triển khai IIS

## Thay đổi

- Thêm `scripts/cai-iis.ps1`: kiểm tra IIS, WebAdministration, ANCM và ASP.NET Core
  runtime; publish Release; tạo/cập nhật App Pool No Managed Code, HTTP site/binding,
  quyền thư mục logs/sao-luu cho `IIS AppPool\<tên-site>`; hỗ trợ `-WhatIf`, `-TenSite`,
  `-Cong`, `-ThuMuc`; không tự tải/cài thành phần IIS.
- Thêm mục IIS vào `docs/trien-khai.md`: target `net8.0`, `RollForward=Major`, Hosting
  Bundle, publish-generated `web.config`, SQL identity, Production config, HTTPS/
  forwarded headers và xử lý 500.19/500.30.
- Thêm lệnh/menu `iis` (mục 8) trong `QuanLyGiaSu.bat`; đánh dấu đề xuất #7 hoàn tất.

## Kết quả kiểm tra

- Cú pháp PowerShell 5.1 theo lệnh yêu cầu
  `powershell -NoProfile -Command "[ScriptBlock]::Create((Get-Content scripts\cai-iis.ps1 -Raw)) | Out-Null"`:
  **OK**.
- `dotnet publish DoAnWeb\DoAnWeb.csproj -c Release -o <thư mục tạm ngoài repo> --nologo`:
  **thành công**; output có `DoAnWeb.dll` và SDK-generated `web.config` dùng
  `AspNetCoreModuleV2`.
- `dotnet build DoAnWeb\DoAnWeb.csproj --nologo`: **0 lỗi, 0 cảnh báo**.
- `scripts\cai-iis.ps1 -WhatIf`: thoát mã **1** với thông báo rõ ràng rằng IIS/
  WebAdministration và ANCM chưa có trên máy; không publish hoặc thay đổi cấu hình.
  Máy có .NET 10 ASP.NET Core Runtime, được phép theo `RollForward=Major`, nhưng thiếu
  Hosting Bundle/ANCM. Không chạy cài IIS thật theo yêu cầu.
- Không sửa `DoAnWeb.csproj`, không commit output publish.
