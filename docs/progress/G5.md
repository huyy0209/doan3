# Tiến độ G5 – Giao diện tối và PWA

## Đã hoàn thành

- Thêm chế độ sáng/tối/tự động; lựa chọn được lưu trong `localStorage`, áp dụng đồng bộ trước CSS và theo dõi thay đổi giao diện hệ điều hành.
- Bổ sung màu tối có độ tương phản cho thẻ, bảng, nhãn, biểu mẫu, trạng thái và thẻ điểm danh trên điện thoại; trang đăng nhập dùng cùng lựa chọn giao diện.
- Thêm manifest, icon PNG 192/512 tạo từ logo hiện có, trang ngoại tuyến và service worker. Service worker chỉ lưu file tĩnh trong `lib/css/js/img/fonts` và `offline.html`; yêu cầu điều hướng chỉ dùng trang offline khi mạng lỗi, không lưu trang HTML có dữ liệu.
- Ánh xạ `.webmanifest` sang `application/manifest+json`; static files được phục vụ trước middleware xác thực.
- Thêm test HTTP cho manifest, trang offline, service worker và nút giao diện trên layout.
- Không thêm mã JavaScript/CSS inline để tương thích CSP.
