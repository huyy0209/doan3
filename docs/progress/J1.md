# J1 – Dọn và sắp xếp lại code dự án web

## Thay đổi

- Chuyển các tệp C# trong `DoAnWeb`, `DoAnWeb.Tests` và `DoAnWeb.E2E`
  sang file-scoped namespace, theo thư mục chứa tệp.
- Chuẩn hóa thư mục `ViewModels` theo tên màn hình, bỏ hậu tố `VM` khỏi tên thư mục,
  cập nhật namespace và tham chiếu trong view, đồng thời chuyển `ErrorViewModel`
  từ `Models/` sang `ViewModels/`.
- Tách service theo vai trò: `Services/Nen/`, `Services/Excel/` và
  `Services/NhatKy/`; giữ `Services/Dto/` và `Services/Validators/`.
- Đổi solution thành `DoAnWeb.slnx` và cập nhật các tham chiếu trong repo.
- Dọn using thừa, định dạng whitespace/style và loại bỏ cảnh báo API lỗi thời
  trong kiểm thử Playwright.
- Cập nhật cấu trúc thư mục trong `README.md`.

## Kiểm tra

- `dotnet build DoAnWeb.slnx`
- `dotnet test DoAnWeb.Tests`
- `dotnet test DoAnWeb.E2E`
- `git grep -n "DoAnWD.slnx"` phải không có kết quả.
