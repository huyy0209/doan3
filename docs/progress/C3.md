# Task C3 – Script kiểm đồng bộ CSDL giữa nhánh app và web

**Mục tiêu:** Tạo script kiểm tra đồng bộ CSDL giữa nhánh `app` và `web`

## Thực hiện

### 1. Tạo script `scripts/kiem-dong-bo-csdl.ps1`

Script PowerShell thực hiện các chức năng:
- Fetch nhánh từ origin (nếu online)
- So sánh nội dung thư mục `Database/` giữa hai nhánh
- Báo cáo file chỉ có ở nhánh A, chỉ có ở nhánh B, và file khác nội dung
- Trả về mã thoát: 0 nếu giống nhau, 1 nếu khác nhau
- Hỗ trợ tham số `-NhanhA` và `-NhanhB` để đổi nhánh so sánh

### 2. Cập nhật `QuanLyGiaSu.bat`

Thêm mục menu "5. Kiểm đồng bộ CSDL app ↔ web" với lệnh `QuanLyGiaSu.bat dong-bo`

### 3. Cập nhật `README.md`

Thêm bảng lệnh và 2 dòng hướng dẫn về cách sử dụng script kiểm tra đồng bộ.

### 4. Kiểm chứng thực tế

#### Chạy script kiểm tra đồng bộ:
```
powershell -ExecutionPolicy Bypass -File scripts/kiem-dong-bo-csdl.ps1
```

**Kết quả:**
```
╔════════════════════════════════════════════════════════════════════════════════════════╗
║ KIỂM TRA ĐỒNG BỘ CSDL - SO SÁNH NHÁNH 'app' vs 'web'                                   ║
╚════════════════════════════════════════════════════════════════════════════════════════╝

[1] Fetch nhánh từ remote...
✓ Đã fetch thành công từ remote

[2] Lấy danh sách file từ Database/...
✓ Nhánh 'app': 15 file
✓ Nhánh 'web': 15 file
[3] KẾT QUẢ SO SÁNH:
┌──────────────────────────────────────────────────────────────────────────────────────┐
║ CHỈ CÓ Ở NHÁNH 'app': (Không có file)
║ CHỈ CÓ Ở NHÁNH 'web': (Không có file)
║ KHÁC NỘI DUNG: (Không có file)
└──────────────────────────────────────────────────────────────────────────────────────┘

[TỔNG KẾT]
✓ Database/ hoàn toàn giống nhau giữa hai nhánh
```

**Chạy với tham số khác:**
```
powershell -ExecutionPolicy Bypass -File scripts/kiem-dong-bo-csdl.ps1 -NhanhA master -NhanhB huyy0209/web-c3
```
→ Hiển thị tương tự, Database/ giống nhau giữa master và web-c3

#### Chạy menu và lệnh:
```
QuanLyGiaSu.bat dong-bo
```
→ Hiển thị menu và chạy script kiểm tra thành công

#### Chạy lệnh không hợp lệ:
```
QuanLyGiaSu.bat abc
```
→ Hiển thị: `[X] Lệnh không hợp lệ: abc`
