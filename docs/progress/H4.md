# H4 – Mở web cho điện thoại từ xa qua Tailscale HTTPS

## Đã thực hiện

- Thêm `scripts/mo-truy-cap-tu-xa.ps1`: kiểm tra Tailscale đang đăng nhập/kết nối và cổng web trước khi bật `tailscale serve --bg --https=443`; hỗ trợ `-Cong`, `-Tat`, `-WhatIf`, in DNS name từ trạng thái Tailscale và cảnh báo không dùng Funnel.
- Bật forwarded headers `X-Forwarded-Proto` / `X-Forwarded-For` trong web, chỉ tin proxy loopback IPv4/IPv6; middleware chạy trước HTTPS redirection để cookie Secure, rate limit và địa chỉ IP request dùng đúng thông tin phía trước proxy.
- Thêm menu và lệnh `QuanLyGiaSu.bat tu-xa`; giữ file `.bat` CRLF và xác nhận nhãn không trùng.
- Bổ sung hướng dẫn truy cập điện thoại bằng Wi-Fi LAN hoặc Tailscale HTTPS, cài PWA, bật `BaoMat:BatBuocHttps` và đổi mật khẩu mặc định.
- Thêm test HTTP xác nhận `X-Forwarded-Proto=https` từ loopback đặt `Request.IsHttps=true`, còn proxy không tin cậy không được áp dụng header.

## Kiểm tra

- `dotnet build DoAnWeb\DoAnWeb.csproj --nologo`: thành công, 0 cảnh báo, 0 lỗi.
- `dotnet test DoAnWeb.Tests\DoAnWeb.Tests.csproj --no-restore --nologo`: 502 đạt, 0 lỗi, 1 bỏ qua.
- Chạy script với `-WhatIf` cho cả Serve và reset; chỉ in lệnh xem trước. Không chạy Serve hoặc Funnel thật. Tailscale trên máy thử đang ở trạng thái `NoState`, nên chưa xác nhận kết nối tailnet thật.
- `QuanLyGiaSu.bat`: nhãn không trùng, 147/147 dòng kết thúc CRLF.
