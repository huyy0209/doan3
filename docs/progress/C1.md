# C1 – CI GitHub Actions cho nhánh web (đề xuất #9)

## Mục tiêu

Mỗi lần push / pull request vào nhánh `web`, GitHub Actions tự build bản web và chạy toàn bộ test
trên **SQL Server 2022 chạy trong container Linux**, có CSDL `QuanLyGiaSu` tạo từ `Database/0*.sql`
+ dữ liệu mẫu. Không dùng SQL Server của máy dev, không đụng dữ liệu thật.

## Nội dung workflow

| Bước | Việc làm |
|---|---|
| Trigger | `push` và `pull_request` vào nhánh `web`; `permissions: contents: read`; hủy lần chạy cũ khi push tiếp cùng nhánh |
| SQL Server | Service container `mcr.microsoft.com/mssql/server:2022-latest`, cổng `1433:1433`, SA password công khai `Ci!QuanLyGiaSu#2026` (container dùng một lần, **không phải mật khẩu thật**) |
| Chờ CSDL | Vòng lặp `sqlcmd` trong container (tự dò `/opt/mssql-tools18/bin/sqlcmd`, bản cũ dùng `/opt/mssql-tools/bin/sqlcmd`), tối đa 300 giây, hết giờ thì in log container và fail |
| Tạo CSDL | `docker cp Database/.` vào container rồi chạy `sqlcmd -C -I -b -f 65001 -i`: cấu trúc `01..08` đúng thứ tự `scripts/CaiDatCSDL.bat`, sau đó dữ liệu mẫu `11..16` (fixture BACKUP/RESTORE cả CSDL nên dữ liệu mẫu sang được CSDL test, giống máy dev) |
| Kiểm thử | `dotnet restore` từng project (SDK 8 chưa đọc được `DoAnWD.slnx`), `dotnet build DoAnWeb/DoAnWeb.csproj -c Release`, `dotnet test DoAnWeb.Tests/DoAnWeb.Tests.csproj -c Release --filter "Can!=SqlServerWindows"` |
| Chuỗi kết nối | Biến `DOANWEB_TEST_SQL` ở cấp workflow: `Server=localhost,1433;User Id=sa;Password=…;TrustServerCertificate=True;MultipleActiveResultSets=True;Connect Timeout=60` |

## Test Windows-only

**Không test nào phải tách lần này.** Mọi test cần CSDL đều đi qua `TestDb` (chuỗi kết nối cấu hình
được) và fixture đã dùng thư mục dữ liệu mặc định của SQL Server, nên chạy được trên container Linux.
Bộ lọc `--filter "Can!=SqlServerWindows"` vẫn đặt sẵn: sau này có test chỉ chạy được trên SQL Server
Windows thì chỉ cần thêm `[Trait("Can", "SqlServerWindows")]`, không phải sửa workflow.

## Kiểm chứng

- Cú pháp YAML: parse bằng PyYAML, đọc đúng `on.push.branches = [web]`, `on.pull_request.branches = [web]`,
  job `build-test`, 7 bước, image `mcr.microsoft.com/mssql/server:2022-latest`.
- `dotnet build DoAnWeb/DoAnWeb.csproj`: 0 lỗi.
- `dotnet test DoAnWeb.Tests/DoAnWeb.Tests.csproj`: 251/251 pass (không đặt biến môi trường – như máy dev).
- Đặt `DOANWEB_TEST_SQL="Server=.;Trusted_Connection=True;TrustServerCertificate=True"`, xóa CSDL
  `QuanLyGiaSu_Test` rồi chạy lại: 251/251 pass → nhánh đọc biến môi trường và nhánh BACKUP/RESTORE
  theo thư mục dữ liệu mặc định đều chạy đúng. Dữ liệu thật `QuanLyGiaSu` không bị ghi.
- **Chưa chạy trên GitHub**: máy không có Docker nên không dựng được container SQL Server 2022 để
  chạy thử; các bước `ubuntu-latest` + container mới chỉ kiểm bằng cú pháp YAML, chưa có kết quả chạy
  thật trên GitHub Actions. Lần push đầu lên nhánh `web` sẽ là lần chạy thật đầu tiên.
