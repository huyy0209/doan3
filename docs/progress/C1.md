# C1 – CI GitHub Actions cho nhánh web (đề xuất #9)

## Mục tiêu

Mỗi lần push / pull request vào nhánh `web`, GitHub Actions tự build bản web và chạy toàn bộ test
trên **SQL Server 2022 chạy trong container Linux**, có CSDL `QuanLyGiaSu` tạo từ `Database/0*.sql`
+ dữ liệu mẫu. Không dùng SQL Server của máy dev, không đụng dữ liệu thật.

## Kiểm chứng

- Cú pháp YAML: parse bằng PyYAML, đọc đúng `on.push.branches = [web]`, `on.pull_request.branches = [web]`,
  job `build-test`, 7 bước, image `mcr.microsoft.com/mssql/server:2022-latest`.
- `dotnet build DoAnWeb/DoAnWeb.csproj`: 0 lỗi.
- `dotnet test DoAnWeb.Tests/DoAnWeb.Tests.csproj`: 251/251 pass (đường mặc định, không đặt biến môi trường).
- Đặt `DOANWEB_TEST_SQL="Server=.;Trusted_Connection=True;TrustServerCertificate=True"`, xóa CSDL
  `QuanLyGiaSu_Test` rồi chạy lại: 251/251 pass → nhánh đọc biến môi trường và nhánh BACKUP/RESTORE
  theo thư mục dữ liệu mặc định đều chạy đúng.
- **Chưa chạy trên GitHub** (máy không có Docker/GitHub Actions): các bước container SQL Server và
  `ubuntu-latest` mới chỉ kiểm bằng cú pháp YAML, chưa có kết quả chạy thật.
