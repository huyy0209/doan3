# E6 – Sao lưu CSDL từ web

- Thêm trang `/SaoLuu` chỉ dành cho `QuanLy`: liệt kê file `.bak`, tải xuống, xóa, và tạo bản sao lưu thủ công.
- `SaoLuuService` chạy lệnh `BACKUP DATABASE` trên đúng CSDL trong chuỗi kết nối; tên CSDL được giới hạn ký tự hợp lệ, đường dẫn SQL dùng tham số. Nếu `SaoLuu:ThuMuc` để trống, thư mục được lấy từ `SERVERPROPERTY('InstanceDefaultBackupPath')`.
- `TuSaoLuuNen` chạy theo `SaoLuu:GioTuDong` (mặc định `23:00`, `Tat` để tắt); mỗi lần sao lưu giữ lại `SaoLuu:GiuSoBan` bản mới nhất (mặc định 14). Hoạt động ghi nhật ký Serilog.
- Không cung cấp chức năng khôi phục trên web; trang hướng dẫn dừng web, ngắt kết nối và khôi phục thủ công bằng SSMS.
- Kiểm thử gồm chặn path traversal, phân quyền HTTP và sao lưu thật `QuanLyGiaSu_Test` rồi xóa file `.bak`; không ghi vào `QuanLyGiaSu`.
