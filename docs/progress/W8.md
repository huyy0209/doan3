# W8 – Gộp file khởi động thành một menu

## Tiến độ

| Mục | Nội dung | Trạng thái |
|---|---|---|
| 1 | Chuyển sáu script `.bat` vào `scripts/`, cập nhật đường dẫn gốc và giữ tham số server CSDL | Hoàn tất |
| 2 | Tạo `QuanLyGiaSu.bat` với menu và các lệnh chạy thẳng | Hoàn tất |
| 3 | Xóa file mẫu và biến thể Bootstrap không được dùng | Hoàn tất |
| 4 | Bổ sung quy tắc `.gitignore` | Hoàn tất |
| 5 | Cập nhật hướng dẫn trong README | Hoàn tất |

Các script trong `scripts/` chuyển về thư mục gốc repo trước khi dùng đường dẫn tương đối. `CaiDatCSDL.bat` và `SaoLuuCSDL.bat` tiếp tục nhận tham số server, ví dụ `.\SQLEXPRESS`. `QuanLyGiaSu.bat` hỗ trợ menu lặp lại và các lệnh `web`, `app`, `stop`, `cai-csdl`, `sao-luu`, `shortcut`.

Trước khi dọn, đã tìm tham chiếu trong `DoAnWeb/`: các layout chỉ nạp `bootstrap.min.css` và `bootstrap.bundle.min.js`; giữ thêm source map tương ứng của hai file này. `_MauGiaoDien.cshtml` không được tham chiếu. `_Layout.cshtml.css` đã không tồn tại và không được Git theo dõi nên không xóa.

## Kiểm tra

- `dotnet build DoAnWeb/DoAnWeb.csproj`: thành công, 0 lỗi.
- `dotnet test DoAnWeb.Tests/DoAnWeb.Tests.csproj`: đạt 240/240 test.
- Chạy `QuanLyGiaSu.bat web`: web phản hồi HTTP 200 tại `http://localhost:5080`.
- Chạy `QuanLyGiaSu.bat stop`: web dừng, cổng 5080 không còn phản hồi.
