# W8 – Gộp file khởi động thành một menu

## Tiến độ

| Mục | Nội dung | Trạng thái |
|---|---|---|
| 1 | Chuyển sáu script `.bat` vào `scripts/`, cập nhật đường dẫn gốc và giữ tham số server CSDL | Hoàn tất |
| 2 | Tạo `QuanLyGiaSu.bat` với menu và các lệnh chạy thẳng | Đang thực hiện |

| 4 | Bổ sung quy tắc `.gitignore` | Chưa thực hiện |
| 5 | Cập nhật hướng dẫn trong README | Chưa thực hiện |

Các script trong `scripts/` chuyển về thư mục gốc repo trước khi dùng đường dẫn tương đối. `CaiDatCSDL.bat` và `SaoLuuCSDL.bat` tiếp tục nhận tham số server, ví dụ `.\SQLEXPRESS`.
