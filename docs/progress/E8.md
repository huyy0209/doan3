# E8 – Kiểm thử giao diện tự động bằng Playwright

Đề xuất #8 (`docs/de-xuat.md`). Project `DoAnWeb.E2E/` (xUnit + `Microsoft.Playwright` 1.49, net8.0 + RollForward Major),
đã thêm vào `DoAnWeb.slnx`. Không sửa code `DoAnWeb/`, không đổi schema CSDL, không ghi vào `QuanLyGiaSu`.

## Cách hoạt động

- `GiaoDienFixture` (collection fixture "E2E", một lần cho cả bộ): `TestDb.DamBaoDaTao()` (tái dùng `DoAnWeb.Tests/TestDb.cs`
  bằng `<Compile Include ... Link>`, tức cùng cách BACKUP/RESTORE ra `QuanLyGiaSu_Test`, đọc `DOANWEB_TEST_SQL`)
  → dọn dữ liệu `E2E_` cũ → nạp dữ liệu → bật web → bật Chromium headless.
- `MayChuWeb`: chạy `dotnet DoAnWeb.dll` (Kestrel thật) ở tiến trình riêng, `ASPNETCORE_URLS=http://127.0.0.1:<cổng trống>`,
  `ConnectionStrings__QuanLyGiaSu` = chuỗi `QuanLyGiaSu_Test`; từ chối khởi động nếu tên CSDL khác `QuanLyGiaSu_Test`.
  Chờ `/TaiKhoan/DangNhap` trả 200 (tối đa 120 giây), `Dispose` kill cả cây tiến trình.
- `DuLieuE2E`: dữ liệu tiền tố `E2E_` / `e2e_` (4 học viên, 2 gia sư, 1 môn, 2 tài khoản, 3 lớp), dọn trước và sau
  khi chạy theo đúng thứ tự khóa ngoại (không dùng `TEST_` / `ITG_` vì CSDL test dùng chung với nhóm test khác).
- `GiaoDienTestBase.Chay`: mỗi test một BrowserContext (cookie riêng); lỗi thì chụp full-page vào
  `DoAnWeb.E2E/artifacts/<tên>-<giờ>.png` rồi ném lại lỗi gốc.

## 5 kịch bản (`KichBanTests.cs`)

1. `K1` Đăng nhập quản lý → URL `/TongQuan`, tiêu đề "Tổng quan" → đăng xuất → vào lại `/TongQuan` bị đẩy về đăng nhập.
2. `K2` Ghép lớp: chọn học viên, môn, ca Sáng, gia sư đang có lớp ở ca đó → dòng kiểm tra `is-loi` "Gia sư đã có lớp…",
   nút Ghép lớp khóa → đổi ca Tối muộn → `is-ok` → nhập học phí + tên lớp → lưu → toast + trang chi tiết →
   lớp có trong danh sách → Hủy lớp → Xóa lớp → hết trong danh sách.
3. `K3` Gia sư đăng nhập → vào thẳng `/DiemDanh` → chọn hôm nay + ca → lưu một dòng (Có mặt, 8,5) → toast "Đã lưu điểm danh", nhãn "Đã lưu".
4. `K4` Học phí: lớp nợ 1.000.000 → thêm lần đóng 400.000 → "Còn nợ 600.000 đ" → xóa lần đóng → "Còn nợ 1.000.000 đ".
5. `K5` Viewport 390×844: nút ☰ mở menu (`is-sidebar-open`, `aria-expanded=true`), Escape đóng;
   Điểm danh dạng thẻ (ẩn `thead`, dòng `display: grid`, có `data-label`, không tràn ngang).

- `.gitignore` có mẫu `*.e2e` (Visual Studio Trace Files) khớp cả thư mục `DoAnWeb.E2E` (Windows không phân biệt hoa thường) nên
  thêm `!DoAnWeb.E2E/` ngay dưới mẫu đó, rồi mới ignore `DoAnWeb.E2E/artifacts/`.
- Sidebar điện thoại khi mở phủ lên nút ☰ (đúng thiết kế, đóng bằng chạm ra ngoài / Escape) nên K5 đóng menu bằng Escape.
- Không phát hiện lỗi giao diện nào (không có `LOI-xx`, không có test Skip).
- CI: job `e2e` dùng `continue-on-error: true` (lần đầu); chưa chạy được trên GitHub Actions ở đây nên chưa xác nhận được trên Linux
  (`playwright.ps1 install --with-deps chromium`, `pwsh` có sẵn trên ubuntu-latest). Bỏ `continue-on-error` khi xanh ổn định.
