# E7 – Chạy web như dịch vụ Windows + mở cho máy khác trong LAN

Đề xuất #7 (`docs/de-xuat.md`). Task **chỉ viết script + tài liệu**: trên máy làm task
**không** cài dịch vụ, **không** mở tường lửa, **không** ghi vào CSDL `QuanLyGiaSu`;
mọi thứ được kiểm ở chế độ xem trước `-WhatIf`. Không đổi schema CSDL.

## Commit 1 – Hỗ trợ chạy như dịch vụ Windows (`feat(web): chạy bản web như dịch vụ Windows`)

- `DoAnWeb/DoAnWeb.csproj`: thêm `Microsoft.Extensions.Hosting.WindowsServices` 8.0.1.
- `DoAnWeb/Program.cs`: thêm đúng một dòng `builder.Host.UseWindowsService();` —
  khi chạy như dịch vụ thì dùng Windows Service lifetime, khi chạy console / `dotnet run`
  vẫn dùng console lifetime như cũ (không đổi hành vi).
- `scripts/cai-dich-vu-web.ps1` (mới):
  - `dotnet publish DoAnWeb\DoAnWeb.csproj -c Release -o <ThuMuc>` (mặc định
    `%ProgramFiles%\QuanLyGiaSuWeb`); nếu dịch vụ đang chạy thì dừng trước để không khóa `.dll`.
  - `sc.exe create "QuanLyGiaSuWeb" binPath= "<dotnet.exe>" "<DoAnWeb.dll>" start= auto`
    (+ `sc.exe description`, `sc.exe failure … restart/60000`).
  - Đặt `ASPNETCORE_URLS` (mặc định `http://0.0.0.0:5080`) và `ASPNETCORE_ENVIRONMENT=Production`
    vào khóa `HKLM\SYSTEM\CurrentControlSet\Services\QuanLyGiaSuWeb` (REG_MULTI_SZ `Environment`).
  - `-MoTuongLua`: `New-NetFirewallRule` cho TCP 5080, **chỉ profile Private**.
  - `-GoBo`: dừng + xóa dịch vụ, gỡ rule tường lửa, giữ thư mục cài để xem log.
  - Kiểm quyền Administrator và báo rõ cách chạy lại (Run as administrator).
  - `-WhatIf`: chỉ in các lệnh sẽ chạy, không thay đổi gì (vẫn chạy được khi không phải Administrator).
- `DoAnWeb/appsettings.Production.example.json` (mới): mẫu `Kestrel:Endpoints`
  HTTP 5080 + HTTPS 5443 dùng file `.pfx`, kèm `BaoMat:BatBuocHttps=true`;
  mật khẩu chỉ là chỗ giữ `DOI_MAT_KHAU_PFX`, không có mật khẩu thật.

Chi tiết cách `sc.exe` nhận `binPath`: phải là một tham số chứa `"dotnet.exe" "DoAnWeb.dll"`,
trong dòng lệnh viết `\"…\" \"…\"`; script dùng `Start-Process -ArgumentList` dạng một chuỗi
để PowerShell chuyển nguyên văn cho `CreateProcess`.

## Commit 2 – Tài liệu triển khai + menu (`docs(web): hướng dẫn triển khai dịch vụ/LAN/HTTPS`)

- `docs/trien-khai.md` (mới): hướng dẫn tiếng Việt từng bước — cần có trước khi cài,
  cài dịch vụ (menu 9 / `dich-vu`), tham số, kiểm tra dịch vụ + xem log ở `logs/`,
  mở cho máy khác trong LAN (IPv4, tường lửa Private, profile mạng, kiểm tra cổng),
  HTTPS cho LAN (`mkcert` hoặc `dotnet dev-certs`, cấu hình Kestrel, `BaoMat:BatBuocHttps`),
  cập nhật phiên bản, quyền `NT AUTHORITY\SYSTEM` trên SQL Server, gỡ dịch vụ,
  bảng xử lý sự cố, và cách chạy `-WhatIf`.
- `QuanLyGiaSu.bat`: thêm mục **9. Cài dịch vụ web (Administrator)** (giữ mục 0 thoát,
  `choice /c 12345690`) và lệnh thẳng `QuanLyGiaSu.bat dich-vu [-MoTuongLua|-GoBo|-WhatIf]`
  gọi `scripts\cai-dich-vu-web.ps1`; cập nhật dòng lệnh không hợp lệ. File vẫn **CRLF**,
  không BOM, các dòng khung menu vẫn đúng 66 ký tự.
- `README.md`: thêm dòng 9 vào bảng menu + một đoạn trỏ tới `docs/trien-khai.md`,
  bổ sung tên script vào phần cấu trúc thư mục.

  `ASPNETCORE_ENVIRONMENT=Production`, `ASPNETCORE_URLS=http://localhost:5099`,

- **Publish**: `dotnet publish -c Release -o <thư mục tạm>` thành công, có `DoAnWeb.dll`
  và `appsettings.Production.example.json`; chép mẫu thành `appsettings.Production.json`
  (giữ nguyên chú thích `//` và placeholder) thì ứng dụng đọc được cấu hình Kestrel
  (báo đúng lỗi không thấy file `.pfx` mẫu) → **JSON có chú thích vẫn hợp lệ** với
  `Microsoft.Extensions.Configuration.Json`.
- **`-WhatIf` không thay đổi máy**: sau khi chạy, `C:\Program Files\QuanLyGiaSuWeb` **không** được tạo,
  dịch vụ `QuanLyGiaSuWeb` và rule tường lửa không xuất hiện.

### Kết quả `cai-dich-vu-web.ps1 -WhatIf -MoTuongLua` (máy chưa phải Administrator)

```
=== Cài bản web Quản lý gia sư làm dịch vụ Windows (đề xuất #7) ===
  Dịch vụ     : QuanLyGiaSuWeb
  Thư mục     : C:\Program Files\QuanLyGiaSuWeb
  Địa chỉ     : http://0.0.0.0:5080
  Tường lửa   : mở cổng TCP 5080 (Private)
  Chế độ      : CÀI / nâng cấp
  Xem trước   : -WhatIf (không thay đổi gì trên máy)

[!] Chưa chạy bằng quyền Administrator, nhưng -WhatIf chỉ in lệnh xem trước nên vẫn tiếp tục được.
    Khi cài thật: chuột phải QuanLyGiaSu.bat → "Run as administrator" (hoặc mở PowerShell bằng quyền Administrator).
--- Bước 1/4: publish bản Release ---
  [WhatIf] dotnet publish "<repo>\DoAnWeb\DoAnWeb.csproj" -c Release -o "C:\Program Files\QuanLyGiaSuWeb" --nologo

--- Bước 2/4: tạo dịch vụ Windows ---
  [WhatIf] sc.exe create "QuanLyGiaSuWeb" binPath= "\"C:\Program Files\dotnet\dotnet.exe\" \"C:\Program Files\QuanLyGiaSuWeb\DoAnWeb.dll\"" start= auto DisplayName= "Quan ly gia su - Ban web"
  [WhatIf] reg.exe add "HKLM\SYSTEM\CurrentControlSet\Services\QuanLyGiaSuWeb" /v Environment /t REG_MULTI_SZ /d "ASPNETCORE_URLS=http://0.0.0.0:5080\0ASPNETCORE_ENVIRONMENT=Production" /f
  [WhatIf] sc.exe description "QuanLyGiaSuWeb" "Quan ly gia su - ban web (ASP.NET Core), nghe http://0.0.0.0:5080"
  [WhatIf] sc.exe failure "QuanLyGiaSuWeb" reset= 86400 actions= restart/60000/restart/60000/restart/60000

--- Bước 3/4: tường lửa (máy khác trong LAN) ---
  [WhatIf] New-NetFirewallRule -DisplayName "QuanLyGiaSuWeb (TCP 5080)" -Direction Inbound -Protocol TCP -LocalPort 5080 -Action Allow -Profile Private

--- Bước 4/4: khởi động dịch vụ ---
  [WhatIf] sc.exe start "QuanLyGiaSuWeb"

[WhatIf] Đã in xong các lệnh sẽ chạy — CHƯA thay đổi gì trên máy.
        Bỏ -WhatIf (và chạy bằng quyền Administrator) để cài thật.
     Địa chỉ trong máy: http://localhost:5080
     Từ máy khác trong LAN: http://192.168.2.4:5080  (nếu đã mở tường lửa)
     Log (Serilog): C:\Program Files\QuanLyGiaSuWeb\logs\doanweb-YYYYMMDD.log
     Gỡ dịch vụ: QuanLyGiaSu.bat dich-vu -GoBo    (hoặc chạy script này với -GoBo)
     HTTPS / chứng chỉ: xem docs/trien-khai.md
```

(Ở trên lược bớt dòng liệt kê IP Tailscale `100.x`; máy thử có 2 IPv4 nên script in cả hai.)

```
=== Cài bản web Quản lý gia sư làm dịch vụ Windows (đề xuất #7) ===
  ...
  Chế độ      : GỠ dịch vụ
  Xem trước   : -WhatIf (không thay đổi gì trên máy)

--- Gỡ dịch vụ ---
  (dịch vụ QuanLyGiaSuWeb chưa được cài)
  (chưa có rule tường lửa "QuanLyGiaSuWeb (TCP 5080)")

[WhatIf] Đã in xong các lệnh gỡ — CHƯA thay đổi gì trên máy.
```

Dịch vụ/rule chưa từng được cài trên máy làm task nên phần gỡ chỉ báo "chưa được cài";
khi đã cài thật, cùng chế độ này sẽ in `sc.exe stop`, `sc.exe delete` và `Remove-NetFirewallRule`.

### Đường gọi từ menu

`QuanLyGiaSu.bat dich-vu -WhatIf` chạy đúng script (đã thử, ra cùng nội dung xem trước).
Trong menu, mục 9 gọi `call :dich_vu` rồi quay lại menu; `choice /c 12345690` nên
`9` → dịch vụ, `0` → thoát, các phím 7/8 không còn hiệu lực.

## Việc còn lại (khi triển khai thật)

- Chạy `QuanLyGiaSu.bat dich-vu -MoTuongLua` bằng quyền Administrator trên máy chủ thật.
- Cấp quyền đăng nhập SQL Server cho `NT AUTHORITY\SYSTEM` (hoặc đổi tài khoản chạy dịch vụ).
- Nếu dùng HTTPS: tạo chứng chỉ, đặt `appsettings.Production.json` cạnh `DoAnWeb.dll`,
  cài CA sang máy khác, mở cổng 5443 (xem `docs/trien-khai.md` mục 5).
